# Windows setup

The app runs locally on Windows. Use **WSL2 + Docker Desktop + Laravel Sail** for
the same environment as Linux. A native **Laravel Herd** path is below if Docker
is not an option.

---

## Option A — WSL2 + Docker Desktop + Sail (recommended)

### 1. Install WSL2

In PowerShell **as Administrator**:

```powershell
wsl --install -d Ubuntu
```

Restart when prompted, create your Ubuntu user, then verify from PowerShell:

```powershell
wsl -l -v
```

The Ubuntu distro should show `VERSION 2`.

### 2. Install Docker Desktop

1. Install [Docker Desktop for Windows](https://www.docker.com/products/docker-desktop/).
2. Settings → General → enable **Use the WSL 2 based engine**.
3. Settings → Resources → WSL Integration → enable your Ubuntu distro.

Verify inside Ubuntu:

```bash
docker --version
docker compose version
```

### 3. Install PHP + Composer inside Ubuntu

Host PHP is only used to run the `sail` shortcut and Composer. Runtime PHP is
the Sail container.

```bash
sudo apt update
sudo apt install -y git unzip php-cli php-mbstring php-xml php-curl php-zip
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer
php -v
composer --version
```

Ubuntu 24.04 ships PHP 8.3, which is fine for Laravel 12. The container runs
PHP 8.4.

### 4. Clone into the Linux filesystem

Use `~/projects`, **not** `/mnt/c/...` (bind mounts from Windows are slow).

```bash
mkdir -p ~/projects && cd ~/projects
git clone https://github.com/abuyusif01/skillbridge-guinea.git
cd skillbridge-guinea
```

### 5. Start the app

```bash
cp .env.example .env
composer install

./vendor/bin/sail up -d
./vendor/bin/sail artisan key:generate
./vendor/bin/sail artisan migrate --seed

./vendor/bin/sail npm install
./vendor/bin/sail npm run dev
```

Open <http://localhost:8000>.

`npm run dev` must stay running while developing. Use a second Ubuntu terminal
for Artisan commands, or run the frontend build once:

```bash
./vendor/bin/sail npm run build
```

### 6. Everyday commands

```bash
cd ~/projects/skillbridge-guinea

./vendor/bin/sail up -d      # start PHP + MySQL
./vendor/bin/sail down       # stop
./vendor/bin/sail test       # PHPUnit
./vendor/bin/sail artisan migrate
./vendor/bin/sail npm run dev
```

### Port conflicts

- If port 8000 is busy, change `APP_PORT` in `.env` (for example `8080`) and
  use `http://localhost:8080`.
- If a local MySQL already uses 3306, add `FORWARD_DB_PORT=33060` to `.env`.
  The app itself still connects to `mysql:3306` inside Docker.

## Option B — Laravel Herd (native Windows)

Use this if you do not want Docker. Herd includes PHP and Composer.

1. Install [Laravel Herd for Windows](https://herd.laravel.com/).
2. Install Node.js 20+.
3. Clone the repo to a normal local folder (avoid OneDrive-synced folders):

   ```powershell
   git clone https://github.com/abuyusif01/skillbridge-guinea.git C:\dev\skillbridge-guinea
   cd C:\dev\skillbridge-guinea
   ```

4. Install dependencies and set up `.env`:

   ```powershell
   composer install
   npm install
   Copy-Item .env.example .env
   php artisan key:generate
   ```

5. Choose a database:

   **SQLite — quickest preview.** Edit `.env`:

   ```dotenv
   DB_CONNECTION=sqlite
   # DB_HOST=mysql
   # DB_PORT=3306
   # DB_DATABASE=skillbridge
   # DB_USERNAME=sail
   # DB_PASSWORD=password
   ```

   Create the file:

   ```powershell
   New-Item database\database.sqlite -ItemType File
   ```

   **MySQL — closest to production.** Install MySQL 8, create database
   `skillbridge`, then set `DB_HOST=127.0.0.1` and your own username/password in
   `.env`. Herd Pro includes MySQL; Docker can also run MySQL alone.

6. Migrate and run:

   ```powershell
   php artisan migrate --seed
   php artisan serve --port=8000
   npm run dev
   ```

   Open <http://localhost:8000>.

SQLite is for local preview only. Production and CI use MySQL 8.4.

## VS Code dev container

The repo includes `.devcontainer/devcontainer.json` generated by Sail.

1. Install Docker Desktop + the VS Code **Dev Containers** extension.
2. Open the repo in VS Code → **Reopen in Container**.
3. In the container terminal:

   ```bash
   composer install
   cp .env.example .env
   php artisan key:generate
   php artisan migrate --seed
   npm install
   npm run dev
   ```

The app is published on port 8000 by Docker; Vite runs on 5173.

## Common problems

| Problem | Fix |
|---|---|
| `docker: command not found` in WSL | Enable WSL integration in Docker Desktop settings |
| Port 80/8000 in use | Change `APP_PORT` in `.env` |
| MySQL port 3306 in use | Add `FORWARD_DB_PORT=33060` to `.env` |
| `vendor/bin/sail` missing | Run `composer install` inside WSL |
| Slow file access | Keep the clone under `~/projects`, not `/mnt/c` |
| Vite page has no styles | Start `npm run dev`, or run `npm run build` |
| Permission errors on `storage/` | `sudo chown -R $USER:$USER storage bootstrap/cache` |
